# Invariant: feature_owner_owns_status

The Feature — including its `status:` — is authored by its owner (@product-manager for business, @system-architect for enabler). @release-train-engineer governs the status transition and records it in the @release-train-engineer-owned program kanban; it does not write the Feature itself.
